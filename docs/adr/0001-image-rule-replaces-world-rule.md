# 影像規則取代世界座標規則

不禮讓改用影像規則（`yield_image_rule.py`）判斷，世界座標規則（`yield_rules.py` 加畫面穩定化）保留但只作實驗用、不再維護。世界座標規則要手動校正、估速度並補償鏡頭移動，在移動中的安全帽鏡頭影片上算出 0 個事件；而禮讓的車不會在行人還在斑馬線上時開進去，所以只需判斷畫面上車、行人、斑馬線是否同時接觸，不需要校正、速度或鏡頭補償。

## Consequences

- 主流程的第一步是斑馬線分割（`segment_crosswalk.py`，Mask2Former Mapillary 模型），該模型為 CC BY-NC-SA，只限非商業用途。
- 影像規則會看接觸之後的 frame（判斷行人是否走上斑馬線），因此只能離線複審，不能即時判斷。
- 外部評估若跑 `track_video.py` 加 `yield_rules.py`，測到的是實驗路徑，不代表主流程。
